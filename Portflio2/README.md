## 🛠️ Tech Stack

---

## ✨ Features
- **Responsive Layout:** Clean display on both mobile and desktop screens.
- **Semantic HTML:** Structured with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **CSS Selectors Showcase:**
  - Element selectors (`body`, `section`, `h1`)
  - Class selectors (`.glowing-name`, `.tagline`, `.card`)
  - ID selectors (`#contact`, `#home`)
  - Descendant & child combinators (`nav a`, `#skills > ul > li`)
  - Pseudo-classes (`nav a:hover`, `.card:hover`)
- **Typography & Color:** Dual Google Fonts pairing with an accessible 5-color palette.
